 # E-Commerce Sales & Customer Analysis

## Project Overview
Analyzed 500+ e-commerce sales records using SQL, Python, Excel, and Power BI to identify sales, profit, customer, product, regional, and monthly trends.

## Tools & Technologies
- SQL (MySQL)
- Python (Pandas, NumPy, Matplotlib)
- Microsoft Excel
- Power BI
- Jupyter Notebook

## Key Analysis
- Sales and profit performance
- Product and category analysis
- Regional sales analysis
- Monthly sales trends
- Payment mode analysis
- Top 10 customer analysis
- Discount analysis
- KPI analysis including Total Sales, Total Profit, Orders, Quantity, and Average Order Value

## Project Files
- `ecommerce_sales_cleaned.csv` – Cleaned dataset
- `E-Commerce_Sales_Analysis.xlsx` – Excel analysis and dashboard
- `ecommerce_sales_analysis.sql` – SQL queries and analysis
- `ecommerce_sales_analysis.ipynb` – Python analysis
- `E-Commerce_Sales_Customer_Analysis.pbix` – Power BI dashboard

## Key Insights
- Electronics generated the highest sales and profit.
- Laptop was the highest-selling product.
- North region recorded the highest sales.
- May recorded the highest monthly sales.
- Debit Card was the highest sales-generating payment mode.
